# Newsletter Tailwind

A simple newsletter subscription form built using Tailwind CSS utility classes.

## Features
- Gradient header banner
- Email input field
- Subscribe button
- Responsive layout using Tailwind flexbox utilities

## Tech Stack
- HTML5
- Tailwind CSS (via PostCSS)

## Setup

1. Install dependencies
```bash
npm install
```

2. Run the app
```bash
npm start
```

3. Open in browser
http://localhost:5173
> Or simply open `index.html` directly in the browser if not using Vite.
