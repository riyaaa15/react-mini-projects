# CineSearch 🎬

A movie search app built with React + Vite using the OMDB API.

## Features

- Search any movie by name
- Displays movie poster, title, year, and type
- Handles missing posters gracefully

## Tech Stack

- React
- Vite
- Axios
- OMDB API

## Getting Started

1. Clone the repo
```bash
   git clone https://github.com/your-username/cinesearch.git
   cd cinesearch
```

2. Install dependencies
```bash
   npm install
```

3. Create a `.env` file in the root and add your OMDB API key
```
   VITE_API_KEY=your_api_key_here
```

4. Run the app
```bash
   npm run dev
```

## API

Get a free API key from: [https://www.omdbapi.com/apikey.aspx](https://www.omdbapi.com/apikey.aspx)
