# GitHub Profile Finder 🔍

A React app to search any GitHub user by username and view their profile details instantly.

## Features
- 🔍 Search any GitHub username
- 🖼️ Displays avatar, name, bio and username
- 📊 Shows public repos and followers count
- 🔗 Direct link to view full GitHub profile
- ⚠️ Error handling for invalid usernames
- ⏳ Loading state while fetching data

## Tech Used
- React
- Fetch API
- GitHub REST API (free, no key required)
- useState hook

## How to Run
```bash
npm install
npm run dev
```
