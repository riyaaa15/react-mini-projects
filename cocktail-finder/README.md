# Cocktail Finder 🍹

A React app to search any cocktail and get its full details including image, category, instructions, and ingredients. Also features a Random Drink button to discover a surprise cocktail.

## Features
- 🔍 Search any cocktail by name
- 🎲 Random Drink button for surprise cocktails
- 🧾 Displays drink image, category, instructions and ingredients
- ⚠️ Error handling for invalid searches
- ⏳ Loading state while fetching data

## Tech Used
- React
- Fetch API
- TheCocktailDB API (free, no key required)
- useState hook

## How to Run
```bash
npm install
npm run dev
```
